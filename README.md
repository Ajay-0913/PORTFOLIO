# Portfolio

Stack: HTML5, CSS3, vanilla JS, Tailwind CSS v4 (browser CDN, zero build), Google Fonts, Lucide icons.

## Run locally
    cd portfolio
    python3 -m http.server 8000      # or: npx serve
Open http://localhost:8000 (an internet connection is needed for the CDN scripts and fonts).

## Customise
Edit the `CONFIG` object at the top of `js/script.js`. Empty values hide their element.
Put images in `assets/images/` and set the paths in `CONFIG`. Accent and theme colours are the CSS variables at the top of `css/style.css`.
